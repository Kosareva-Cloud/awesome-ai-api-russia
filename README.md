## Зачем этот список

Прямой доступ к API OpenAI, Anthropic и Google из России закрыт: запросы с российских IP отклоняются по региону, а карты российских банков на этих платформах не принимаются. Из-за этого разработчики собирают обходные пути по чатам и статьям, и каждый раз заново. Здесь собрано то, что работает: клиенты, которым можно указать свой адрес API, библиотеки с настраиваемым `base_url`, официальные страницы вендоров с описанием ошибок и способы запустить модель у себя. Список описательный — что это за инструмент и как в нём задаётся адрес; выбор остаётся за читателем.

## Прямой доступ к вендорам

Первоисточники: там выходят модели и документация. Из России все они требуют зарубежного IP и зарубежного платёжного средства.

- [Claude Console](https://platform.claude.com/) — API моделей Claude, Anthropic-формат сообщений; оплата зарубежной картой, регистрация требует зарубежного номера и IP.
- [DeepSeek](https://www.deepseek.com/) — API моделей DeepSeek, OpenAI-совместимый формат; пополнение баланса из России картой не проходит.
- [Google AI Studio (Gemini API)](https://ai.google.dev/) — API моделей Gemini, есть бесплатный уровень; платный уровень привязан к биллингу Google Cloud с зарубежной картой.
- [Groq](https://groq.com/) — инференс открытых моделей на собственных ускорителях, OpenAI-совместимый API; оплата зарубежной картой.
- [Mistral AI](https://mistral.ai/) — API моделей Mistral и открытые веса части из них; оплата зарубежной картой.
- [OpenAI Platform](https://platform.openai.com/) — API моделей GPT, аудио, изображений и эмбеддингов; пополнение только зарубежной картой, доступ из РФ ограничен по региону (`unsupported_country_region_territory`).
- [OpenRouter](https://openrouter.ai/) — маршрутизатор к моделям множества вендоров через один ключ; пополнение зарубежной картой или криптовалютой, доступ из РФ ограничен.
- [xAI](https://x.ai/) — API моделей Grok, OpenAI-совместимый формат; оплата зарубежной картой.

## Редакторы и агенты

Что можно подключить к стороннему адресу API вместо адреса вендора.

- [Aider](https://aider.chat/) — помощник для работы с git-репозиторием в терминале; модели задаются через LiteLLM, в том числе OpenAI-совместимые адреса.
- [Cherry Studio](https://cherry-ai.com/) — десктопный клиент для Windows, macOS и Linux; провайдер с произвольным Base URL, история хранится локально.
- [Claude Code](https://claude.com/claude-code) — терминальный агент Anthropic; адрес шлюза задаётся переменной `ANTHROPIC_BASE_URL`, ключ — `ANTHROPIC_AUTH_TOKEN`.
- [Cline](https://cline.bot/) — агент в VS Code; провайдер `OpenAI Compatible` с произвольным Base URL, отдельно поддерживается Anthropic-формат.
- [Codex CLI](https://github.com/openai/codex) — терминальный агент OpenAI; в `~/.codex/config.toml` описывается свой провайдер с `base_url` и переменной ключа.
- [Continue](https://continue.dev/) — расширение для VS Code и JetBrains; в конфиге у каждой модели задаётся `apiBase` любого OpenAI-совместимого адреса.
- [GitHub Copilot](https://code.visualstudio.com/docs/copilot/customization/language-models) — ассистент в VS Code; в Manage Language Models → Add Models → Custom Endpoint добавляется свой адрес API и ключ, модели доступны в чате и режиме агента.
- [Kilo Code](https://kilo.ai/) — агент в VS Code; провайдер `OpenAI Compatible` с произвольным Base URL, размер контекста модели задаётся в `kilo.jsonc`.
- [LM Studio](https://lmstudio.ai/) — десктопное приложение для локальных моделей; поднимает локальный OpenAI-совместимый сервер, к которому обращаются другие клиенты.
- [n8n](https://n8n.io/) — сценарии автоматизации; в креденшелах узлов OpenAI и Anthropic указывается свой Base URL.
- [Ollama](https://ollama.com/) — запуск моделей на своей машине; OpenAI-совместимый эндпоинт на `localhost:11434/v1`.
- [Open WebUI](https://openwebui.com/) — self-hosted веб-интерфейс чата; подключается к любому OpenAI-совместимому адресу и к локальной Ollama.
- [opencode](https://opencode.ai/) — терминальный агент; свой провайдер описывается в `opencode.json` через пакет `@ai-sdk/openai-compatible` с `baseURL`.
- [Zed](https://zed.dev/) — редактор со встроенным ассистентом; в настройках описывается свой провайдер с указанием адреса API.

## Библиотеки и SDK

- [anthropic](https://github.com/anthropics/anthropic-sdk-python) — официальный клиент Anthropic; `base_url` в конструкторе или `ANTHROPIC_BASE_URL` в окружении.
- [google-genai](https://github.com/googleapis/python-genai) — официальный клиент Google для Gemini API и Vertex AI.
- [LangChain](https://www.langchain.com/) — фреймворк для приложений на LLM; в `ChatOpenAI` и соседних классах передаётся свой `base_url`.
- [LiteLLM](https://github.com/BerriAI/litellm) — общий интерфейс к сотне провайдеров и прокси-сервер с ключами, лимитами и логами расхода.
- [LlamaIndex](https://www.llamaindex.ai/) — фреймворк для индексов и RAG поверх тех же клиентов.
- [openai (Node.js)](https://github.com/openai/openai-node) — тот же клиент для JavaScript и TypeScript, `baseURL` в конструкторе.
- [openai (Python)](https://github.com/openai/openai-python) — официальный клиент OpenAI; адрес меняется параметром `base_url` или переменной `OPENAI_BASE_URL`.
- [Vercel AI SDK](https://ai-sdk.dev/) — TypeScript SDK со стримингом и переключением моделей; у провайдера настраивается `baseURL`.
- [Документация API kosareva.cloud](https://kosareva.cloud/docs/) — примеры запросов на Python, Node и curl к OpenAI-совместимому адресу.

## Оплата и документы

Три способа оплатить зарубежный API из России и то, чем они отличаются на практике.

- **Зарубежная виртуальная карта** — карта банка другой страны, выпущенная на физлицо. Платёж проходит напрямую у вендора, закрывающих документов для российской бухгалтерии нет, карта может перестать работать при проверке платежа.
- **Платёж через посредника** — физлицо или компания оплачивает счёт вендора за вас. Доступ остаётся вашим, но расход попадает в учёт как услуга посредника, а не как оплата API.
- **Счёт от юрлица с закрывающими документами** — договор, счёт, акт, инвойс, обмен через ЭДО. Оплата идёт в рублях банковским переводом, расход попадает в учёт как оплата ИТ-услуг. Этот способ единственный, который проходит проверку бухгалтерии и не зависит от судьбы конкретной карты.

Что имеет смысл выяснить до подключения, каким бы способом вы ни платили: в какой валюте фиксируется цена и что происходит при скачке курса, выдаются ли закрывающие документы и какие именно, как считается расход — по токенам вендора или во внутренней валюте сервиса, и что будет с неизрасходованным остатком, если вы уйдёте.

## Справочники и диагностика ошибок

- [Claude API: Errors](https://platform.claude.com/docs/en/api/errors) — коды и типы ошибок Anthropic, лимиты размера запроса, `request-id` для обращения в поддержку.
- [Gemini API: Troubleshooting](https://ai.google.dev/gemini-api/docs/troubleshooting) — коды ошибок Google, блокировки по безопасности, стратегии повторов.
- [OpenAI: Error codes](https://developers.openai.com/api/docs/guides/error-codes) — официальный разбор 400, 401, 429, 500 и ошибок клиентских библиотек.
- [Справочник ошибок API](https://kosareva.cloud/spravochnik/) — разборы кодов ответов, ошибок провайдеров и настроек инструментов на русском.

## Локальные модели

Когда данные не должны уходить наружу или нужен нулевой счёт за токены.

- [gpt-oss](https://github.com/openai/gpt-oss) — открытые веса моделей OpenAI (`gpt-oss-120b`, `gpt-oss-20b`) под лицензией Apache 2.0.
- [llama.cpp](https://github.com/ggml-org/llama.cpp) — инференс на C/C++ для CPU и GPU, формат GGUF, встроенный HTTP-сервер.
- [LM Studio](https://lmstudio.ai/) — графическое приложение: каталог моделей, чат и локальный сервер API.
- [Ollama](https://ollama.com/) — запуск открытых моделей одной командой, OpenAI-совместимый эндпоинт локально.
- [vLLM](https://github.com/vllm-project/vllm) — серверный инференс с батчингом и PagedAttention, OpenAI-совместимый API.

## Как добавить инструмент

Pull request с одной строкой в нужный раздел. Правила:

1. Формат строки: `- [Название](ссылка) — что это и как в нём задаётся адрес API.` Одно предложение, без второго абзаца.
2. Тон нейтральный: факты о сервисе. Оценок в духе «быстрее всех», «дешевле аналогов», превосходных степеней и рекламных эпитетов в описании быть не должно.
3. Ссылка ведёт на официальный сайт или репозиторий, без реферальных параметров и промокодов.
4. Сервис должен работать из России на момент подачи PR: доступ без обхода блокировок либо явно описанный способ оплаты из РФ.
5. Внутри раздела строки идут по алфавиту — вставляйте свою на нужное место.
6. Неработающие и закрывшиеся сервисы удаляются из списка; PR на удаление принимается так же, как на добавление.

Подробнее — в [CONTRIBUTING.md](CONTRIBUTING.md).
